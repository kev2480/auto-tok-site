Privacy Policy

Last updated: 18 October 2026

1. Summary

auto-tok is a personal tool used only by its owner to post videos to the owner's own TikTok account. It does not collect, store or process data about any other person.

2. TikTok permissions (scopes) requested

  • user.info.basic — to read the owner's basic profile (open ID, display name, avatar) and confirm the correct account is connected.
  • video.upload — to upload generated videos to the owner's account.
  • video.publish — to publish those videos to the owner's own profile.

3. How tokens are stored

The OAuth access and refresh tokens issued by TikTok are stored only locally, on the owner's own machine. They are never uploaded to any server operated by auto-tok, and are never shared with or sold to anyone.

4. Data about other users

auto-tok does not collect any information about other TikTok users, viewers or followers.

5. This website

This website is static. It sets no cookies, runs no analytics or tracking, and loads no third-party scripts. The OAuth callback page only displays the address it was opened with so the owner can copy it into their own terminal; it does not send that address anywhere.

6. Revoking access

Access can be revoked at any time in the TikTok app: Settings and privacy → Security → Manage app permissions, then remove auto-tok. Deleting the locally stored token file also stops the tool from posting.
